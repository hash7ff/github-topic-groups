GitHub Topic Folders

See your GitHub repositories as folders, GitLab-group style. Powered by nothing but GitHub Topics.

Install Source on GitHub

How it works

Give a repository a topic that starts with topic-folders-. That is the whole data model.

Repositories                      Repositories (grouped)

api        topic-folders-client-a     ▼ Client A  (3)
frontend   topic-folders-client-a         api
firmware   topic-folders-client-a         frontend
cool-lib   topic-folders-oss              firmware
test-tool                             ▶ OSS  (1)
                                      ▼ Ungrouped  (1)
                                          test-tool
  • Topics are the source of truth. There is no hidden database. Uninstall the extension and your classification is still on GitHub, as plain topics. Use another machine and it is already there.
  • Repositories keep their names. No client-a-api prefixes; api stays api.
  • Your other topics are never touched. Moving a repository between projects rewrites only the topic-folders-* topic.
  • Always escapable. A Grouped | Original switch brings back GitHub's own list at any time.

Install

The extension is in early development and not yet on the Chrome Web Store. Developers can build it from source and load it unpacked. This page will link to the store listing when it is available.

Privacy

The extension talks only to GitHub. Your GitHub credentials stay in your browser and are sent to api.github.com only. No analytics, no third-party servers. It reads your repository list and replaces repository topics when you ask it to; it cannot delete repositories. Read the privacy policy.

Note: GitHub topic names are public even on private repositories. Do not use confidential client or project names as project topics.
