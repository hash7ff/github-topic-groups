Privacy Policy

Topic Groups for GitHub (Chrome extension) · Effective 2026-09-03, last updated 2026-09-03

This policy describes what the Topic Groups for GitHub browser extension ("the extension") does with data. The extension is developed and published by HASH7FF LLC (合同会社HASH7FF), Tokyo, Japan ("we"). Contact: contact@hash7ff.com.

Summary

  • The extension communicates only with GitHub (api.github.com and github.com). We operate no servers and receive no data from you.
  • Your GitHub credentials are stored only in your browser.
  • There are no analytics, no tracking, no advertising and no third-party services.
  • The extension changes GitHub data in exactly one way: it replaces the topics of a repository, and only when you explicitly ask it to.

Data the extension handles

  • GitHub credentials. Either a personal access token you paste into the extension's settings, or an access token and refresh token obtained when you use "Sign in with GitHub" (GitHub's device authorization flow). The credential is stored in the browser's extension storage (chrome.storage.local) on your device, with access restricted to the extension's trusted contexts (its service worker and settings page). It is sent to api.github.com (and, for sign-in and token refresh, github.com) to authenticate requests, and nowhere else. It is never exposed to web pages and never logged.
  • Repository metadata. Names, visibility, descriptions, languages, update times and topics of the repositories you own or that belong to an organization whose repository page you open, and your GitHub login name, fetched from the GitHub API. This is cached in the browser's session storage to avoid repeated requests and is discarded when the browser closes.
  • Write journal. Before each topic change the extension records, locally in chrome.storage.local, the repository name and its topics before and after the change (the last 200 entries, including dry runs). This exists so a mistake can be traced and undone by hand. It is never transmitted.
  • Preferences. Which groups are collapsed, whether the grouped or original view is shown, the group-topic prefix, and the dry-run setting. Stored locally in the browser.

The extension does not collect or store your name, email address, browsing history, or any data from web pages other than the GitHub repositories page it operates on.

What the extension does on GitHub

The extension calls only these GitHub REST API endpoints: GET /user, GET /user/repos, GET /orgs/{org}/repos, GET /user/installations, GET /repos/{owner}/{repo}/topics and PUT /repos/{owner}/{repo}/topics, plus GitHub's OAuth device-flow endpoints on github.com for sign-in and token refresh. Writes happen only in response to an action you take (creating, moving, renaming or deleting a group, or fixing a conflict) and replace the repository's topic list while preserving every topic that does not start with the group prefix you configured (default topic-groups-). Because GitHub's topics API replaces the whole list, a topic added by someone else in the fraction of a second between the extension reading and writing the list could be lost; the extension re-reads the list immediately before each write to keep that window as small as possible. The extension cannot create, delete, or otherwise modify repositories.

Please note that GitHub registers topic names globally, even when a topic is used only on private repositories, so avoid company, client or engagement names; the extension warns about this. Your repositories themselves are not exposed by this: GitHub's public topic pages list public repositories only.

Permissions

  • storage — to keep your credential and preferences in the browser.
  • Access to github.com — to show the grouped view on your repositories page.
  • Access to api.github.com — to read your repositories and update topics.

Data retention and deletion

All data lives in your browser. Use "Clear token" / "Sign out" in the extension's settings to remove the credential, or uninstall the extension to remove everything it stored. You can also revoke the token or the authorization on GitHub at any time (Settings → Developer settings, or Settings → Applications).

Limited use

Data obtained through the extension is used only to provide the grouped-repositories feature the user requested. It is not sold, not used for advertising, not used to determine creditworthiness or for lending, and not transferred to anyone other than GitHub (as needed to perform the requested actions) or as required by law.

Children

The extension is not directed at children under 13 and does not knowingly process their data.
