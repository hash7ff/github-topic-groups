Advanced

Topics starting with this prefix are shown as groups; e.g. topic-groups-platform becomes the group Platform. Lowercase letters, numbers and hyphens, ending with a hyphen. This setting lives in this browser only: repositories tagged with a different prefix are not recognised as folders until re-tagged. Choose a prefix nobody uses for anything else, because "Delete group" removes topics with this prefix.

Use a personal access token instead of signing in

For people who prefer a token. Fine-grained token with Metadata: Read-only and Administration: Read and write (create one). Saving a token replaces the GitHub sign-in.

Important

  • Topic names are registered globally on GitHub, even when used only on private repositories, so avoid company, client or engagement names. GitHub says so itself: “Topic names are always public, even if you create the topic from within a private repository.”
  • Your private repositories are not exposed. GitHub's public topic pages list public repositories only, and a topic used solely on private repositories is indistinguishable from one nobody has ever used (verified 2026-09-05).
  • Your GitHub credential is stored locally in this browser profile (chrome.storage.local) and is sent only to GitHub. It is never given to the GitHub web page or written to logs.
  • This extension only reads your repository list and replaces repository topics. It never deletes repositories or changes anything else.
  • Every topic outside the group prefix is preserved when a repository is moved between groups.
