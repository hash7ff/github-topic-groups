Advanced

Topics starting with this prefix are shown as folders; e.g. topic-folders-client-a becomes the folder Client A. Lowercase letters, numbers and hyphens, ending with a hyphen. This setting lives in this browser only: repositories tagged with a different prefix are not recognised as folders until re-tagged. Choose a prefix nobody uses for anything else, because "Delete project" removes topics with this prefix.

Use a personal access token instead of signing in

For people who prefer a token. Fine-grained token with Metadata: Read-only and Administration: Read and write (create one). Saving a token replaces the GitHub sign-in.

Important

  • Topic names are public, even on private repositories. Do not use confidential client or project names as project topics.
  • Your GitHub credential is stored locally in this browser profile (chrome.storage.local) and is sent only to GitHub. It is never given to the GitHub web page or written to logs.
  • This extension only reads your repository list and replaces repository topics. It never deletes repositories or changes anything else.
  • Every topic outside the folder prefix is preserved when a repository is moved between projects.
